サーバー（ブラウザ表示）とは

Pyokomin の中で小さなサーバーを動かすと、レーンのコメントを1枚のページとして出せます。このページを OBS やブラウザで開くと、配信の画面などにコメントを載せられます。

止めていても大丈夫

  • Pyokomin のいつもの画面は、このサーバーを通りません。サーバーが要るのは、OBS やブラウザにコメントを出すときだけです
  • 動かす・止めるは、上のバーの「ブラウザ表示」の吹き出しの［始める］［止める］で。「起動時に始める」に印を付けると、Pyokomin を起動したときに自動で動かします（はじめは動かしません）

このパソコンの中だけ

  • サーバーは、このパソコンの中からだけ見られます。家の中のほかのパソコンやスマホからは見られません
  • ページの中には、起動のたびに作り直す合言葉が入っています。合言葉の無い読み込みには、コメントを返しません。ほかのサイトから読みに来ても断ります

住所の番号（ポート）

  • サーバーの住所は http://127.0.0.1:8080/… のような形で、最後の数字（ポート）は 8080 から始めます
  • ほかのアプリが 8080 を使っていたら、8081、8082… と空いている番号を探します。番号が変わると URL も変わるので、OBS に貼った URL を貼り直すことがあります
  • 番号は、設定の「ブラウザ表示」の欄の「ポート」で変えられます
