記録の暗号化

Pyokomin は、見た配信のコメントを、あとで読み返せるようにパソコンの中に残します。この記録を暗号化できます。

何が守られるか

  • 暗号化すると、Pyokomin の記録のファイル（コメントの記録）を、Pyokomin の外から読めなくなります。パソコンを人に貸したときや、ファイルだけを持ち出されたときにも、中身を読まれにくくなります
  • 暗号化しないもの: 共有で受け取ったファイル・絵文字の画像・動作の記録（ログ）・設定の値・画面を表示する部品の置き場所。これらは記録のファイルと別の所にあります
  • 報告の履歴と、報告に付けた画面の写しは、これから暗号化する予定です（いまはまだ暗号化していません）

鍵はどこにあるか

  • 暗号化の鍵は、Windows がその利用者のために預かります。そのため、同じパソコン・同じ Windows の利用者なら、合言葉を打たずにそのまま使えます
  • 別のパソコンへ移したとき・Windows を入れ直したときは、Windows が預かった鍵を使えないので、記録を開けません。同じ Microsoft アカウントでも、別のパソコンでは開けません
  • そのときのために、設定の「データの暗号化」から鍵を書き出しておけます（合言葉で包んだ1つのファイル）。鍵のファイルと合言葉があれば、別のパソコンでも記録を開けます
  • 鍵のファイルと合言葉の両方を失くすと、別のパソコンや Windows の入れ直しのあとは、記録を開けません。 鍵のファイルは、記録と別の場所に保管してください

選べる方式

  • 設定の「データの暗号化」で、「自動」「AEGIS-256」「ChaCha20-Poly1305」「暗号化しない」から選べます。はじめは「暗号化しない」です
  • 「自動」は、パソコンの頭脳（CPU）に合わせて、速い方を選びます
  • 切り替えるときは、見ている配信を閉じて、Pyokomin が一度起動し直します。記録が多いと少し時間がかかります

開けないと出たとき

  • 「暗号化した記録を開けません」と出たら、［鍵のファイルを読み込む…］で書き出した鍵を読み込んでください
  • ［記録を新しく始める］を選んでも、今の記録は消さずに、名前を変えて残します
