Pyokomin ガイド

Pyokomin は、YouTube ライブのチャットをレーンに分けて読むための Windows アプリです。いまはベータ版です。

動作環境

  • Windows 11（64 ビット。Windows 10 は確かめていません）
  • Microsoft Edge WebView2 ランタイム（Windows 11 には最初から入っています）
  • インターネット接続

入れ方と起動

  1. 配布された zip ファイルを、好きなフォルダに展開します。
  2. 展開したフォルダの pyokomin.exe を起動します。
  3. 初回だけ、ベータ版の説明とログインの案内が出ます。ログインはあとからでもできます。

インストーラーはありません。アプリ本体は展開したフォルダの中にすべて入っています。

データの保存場所

Pyokomin のデータは、すべてこの PC の中に保存されます。チャットの記録を開発者のサーバーへ送ることはありません。

何が場所
チャットの記録・絵文字の画像ドキュメント\pyokomin.sqlite と ドキュメント\pyokomin_emojis
設定・ログイン情報（暗号化して保存）%APPDATA%\com.ymoage\pyokomin
アプリ内の YouTube 画面のデータ（ログイン状態など）%LOCALAPPDATA%\flutter_webview_windows\pyokomin
チャットを読むためのブラウザアプリを展開したフォルダの中の .local-chrome

%APPDATA% などは、エクスプローラーのアドレス欄にそのまま貼り付けると開けます。

ドキュメントフォルダを OneDrive で同期している場合、チャットの記録も OneDrive に送られます。望まない場合は、OneDrive の設定でドキュメントフォルダの同期（バックアップ）を外してください。

アンインストール

  1. Pyokomin を閉じます。
  2. アプリを展開したフォルダを削除します。
  3. データも消す場合は、上の表の場所を削除します。
    • ドキュメント\pyokomin.sqlite と ドキュメント\pyokomin_emojis
    • %APPDATA%\com.ymoage\pyokomin
    • %LOCALAPPDATA%\flutter_webview_windows\pyokomin

レジストリやスタートメニューには何も登録していません。

不具合の報告

  • Ctrl+Shift+B で、スクリーンショット付きの報告を送れます。送る前に、送られる画面と中身を確かめられます。送ると受付番号が出ます。
  • アプリが不具合を見つけたときは、エラーの種類とバージョンだけを自動で開発者に送ります。名前・チャットの本文・チャンネルは送りません。設定でオフにできます。

詳しくは プライバシーポリシー をご覧ください。
