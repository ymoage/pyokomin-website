Pyokomin のはじめかた

Pyokomin は、YouTube ライブのチャットをレーンに分けて読むための Windows のアプリです。いまは β版です。無料で使えます（正式版になっても無料です）。

動作環境

  • Windows 10・11（64 ビット）
  • Microsoft Edge WebView2 ランタイム（Windows 11 には最初から入っています。無いときは、インストーラーが案内します）
  • インターネット接続

入れかたは2つ

インストーラー（おすすめ）か zip の、どちらか一方を使ってください。両方を使うと、同じ場所に入るので、あとで消すときに残りが出ます。

インストーラーで入れる

  1. ダウンロードのページ から Pyokomin-Setup-（版）.exe をダウンロードします
  2. ダウンロードしたファイルを開きます。Windows の警告が出たら、下の「Windows の警告が出たら」をご覧ください
  3. 利用規約を読み、「同意する」を選んで進みます
  4. 「インストール」を押します。管理者の権限は要りません
  5. 終わったら、スタートメニューの Pyokomin から起動します
  • 入る場所: %LOCALAPPDATA%\Programs\Pyokomin
  • 新しい版にするとき: 新しいインストーラーを同じように走らせます。記録と設定はそのまま残ります。Pyokomin を開いたままだと、閉じてよいかを聞かれます
  • やめるとき: Windows の「設定」→「アプリ」→「インストールされているアプリ」で Pyokomin を選び、「アンインストール」。記録と設定は残ります（消しかたは下の「記録と設定も消すとき」）

zip で入れる

インストーラーを使いたくない人向けです。

  1. ダウンロードのページ から Pyokomin-（版）-win-x64.zip をダウンロードします
  2. （警告を減らしたいとき）zip を右クリック →「プロパティ」→ 下のほうの「許可する」にチェック →「OK」
  3. zip を右クリック →「すべて展開」を選びます
  4. 展開先の欄を消して、%LOCALAPPDATA%\Programs と入れ、「展開」を押します
  5. 開いたフォルダの中の Pyokomin → pyokomin（種類が「アプリケーション」のもの）をダブルクリックします
  6. よく使うなら、pyokomin を右クリック →「スタートにピン留めする」

展開すると %LOCALAPPDATA%\Programs\Pyokomin ができます。フォルダの中の 利用規約.txt は、インストーラーで出るものと同じ利用規約です。

展開しないでほしい場所

場所わけ
zip を開いたまま（展開せずに中の pyokomin を起動）一時的な場所で動くので、うまく動かなかったり、閉じると消えたりします
C:\Program Files管理者の権限が要り、新しい版にするたびに困ります
デスクトップ・ドキュメント・OneDrive の中同期のせいで重くなったり、使っている最中に止まったりすることがあります
ダウンロードのフォルダに置いたまま片付けのときに、一緒に消してしまいやすいです

新しい版にするとき

  1. Pyokomin を閉じます
  2. %LOCALAPPDATA%\Programs\Pyokomin のフォルダを消します
  3. 新しい zip を、上と同じ手順で %LOCALAPPDATA%\Programs に展開します

消すのは Programs の中の Pyokomin だけです。 記録は %LOCALAPPDATA%\Pyokomin（Programs の外）という、名前のよく似た別のフォルダにあります。こちらを消すと、チャットの記録がなくなります。

やめるとき

%LOCALAPPDATA%\Programs\Pyokomin を消します。記録と設定も消すときは、下の「記録と設定も消すとき」をご覧ください。

Windows の警告が出たら

Pyokomin は個人で作っているアプリで、有料の証明書を持っていません。そのため、はじめは Windows やブラウザが「見慣れないアプリ」として警告します。この警告を出さないようにする方法は、いまはありません。

ダウンロードのとき（Edge など）

Edge では、ダウンロードの一覧に「…は一般的にダウンロードされていません」と出て、ダウンロードが止まることがあります。

  1. その行のメニュー（…）から「保存」を選びます
  2. 出てきた画面で、「削除」の横の「∨」を押し、「保持する」を選びます

（Chrome では、ふつうは警告が出ません）

開くとき（「Windows によって PC が保護されました」）

  1. 「詳細情報」を押します
  2. 「アプリ」の欄が Pyokomin-Setup-（版）.exe（zip のときは pyokomin.exe）で、「発行元」が「不明な発行元」であることを確かめます
  3. 「実行」を押します

ダウンロードしたものが本物か確かめたいとき

ダウンロードのページの SHA256SUMS.txt に、ファイルごとの値が書いてあります。PowerShell で次のように打つと、手元のファイルの値が出ます。同じなら、配ったものと同じです。

Get-FileHash "ダウンロードしたファイル" -Algorithm SHA256

署名について

Pyokomin のアプリとインストーラーには、開発者が自分で作った証明書で署名しています。

  • 証明書の指紋: B85AEAC18BD50A84506DD4593B37E08453EDF03B
  • 署名を見るには: ファイルを右クリック →「プロパティ」→「デジタル署名」。署名者の名前が「Pyokomin (ymoage)」で、詳細の証明書の指紋が上と同じなら、開発者が署名したものです
  • 証明書を Windows に入れる必要はありません。署名で分かるのは「誰が作ったか」と「途中で書き換えられていないか」で、Windows の警告が出るかどうかとは別です

はじめにすること

  1. YouTube にログインする: 上のバーの YouTube の札 →「YouTube にログイン」。ログインは Pyokomin の中の窓で行います。パスワードは開発者に届きません。ふだんお使いのブラウザのログインとは別です
    • 途中で Google のアカウントの確認を求められたら、Pyokomin は窓を閉じてお知らせします。いつものブラウザで Google を開いて確認を済ませてから、もう一度ログインしてください
  2. 配信を開く: 見たい配信の URL をコピーして、Pyokomin の画面で Ctrl+V を押します。配信を開く入口（＋）の中で右クリック →「URL を貼り付けて開く」でも開けます
  3. ログインしなくても、チャットを読むことはできます。コメントを送るとき・メンバー限定の配信を読むときにログインが要ります

記録と設定の置き場所

Pyokomin の記録と設定は、すべてこの PC の中にあります。チャットの記録を開発者のサーバーへ送ることはありません。

何が場所
チャットの記録・絵文字の画像%LOCALAPPDATA%\Pyokomin
設定・ログインの情報（Google のサインインは暗号化して保存）・不具合の報告の控え%APPDATA%\com.ymoage\pyokomin
アプリの中の YouTube の画面のデータ（YouTube のログインの状態など）%LOCALAPPDATA%\flutter_webview_windows\pyokomin

このほか、Windows のサウンドの設定（コントロールパネルの「サウンド」）に、Pyokomin の操作の音の項目を登録しています。インストーラーで入れた場合は、アンインストールで外れます。

%LOCALAPPDATA% などは、エクスプローラーのアドレス欄にそのまま入れると開けます。

記録と設定も消すとき

  1. Pyokomin を閉じます（アンインストールか、zip のフォルダを消すのも先に済ませます）
  2. 上の表の3つのフォルダを消します

不具合の報告

  • アプリの上のバーの虫のボタン（または Ctrl+Shift+B）で、画面の写し付きの報告を送れます。送る前に、送られる画面と中身を確かめられます。送ると受付番号が出ます
  • アプリが不具合を見つけたときは、エラーの種類と版だけを自動で開発者に送ります。名前・チャットの本文・チャンネルは送りません。設定でオフにできます
