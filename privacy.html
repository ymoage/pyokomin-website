プライバシーポリシー

最終更新日: 2026年11月24日

1. はじめに

Pyokomin（以下「本アプリ」）は、YouTube ライブのチャットを読むための Windows のアプリです。個人の開発者が、営利を目的とせずに作っています。

このページでは、本アプリがどんな情報を扱い、どこに置き、何に使うかを説明します。

2. 扱う情報

2.1 YouTube のログイン

本アプリの中の窓で YouTube にログインできます。ログインすると、コメントを送ったり、メンバー限定の配信のチャットを読んだりできます。

  • ログインの情報（YouTube の Cookie）は、この PC の中の本アプリの置き場にだけ保存されます
  • 開発者のサーバーには送りません。パスワードを本アプリが読むこともありません
  • ふだんお使いのブラウザのログインとは別のものです

2.2 Google のサインイン

本アプリの一部の機能（リンク・画像・ファイルを添える、配信者が自分のチャンネルで受け付けるものを決める、など）は、Google のサインインを使います。サインインは、いつもお使いのブラウザで行います。

本アプリが Google に頼む許可と、使い方は次のとおりです。

  • メールアドレス・表示名・プロフィール画像: どのアカウントでサインインしているかを、アプリの中に示すため
  • YouTube のアカウント: あなたの YouTube のチャンネルがどれかを確かめるため。同意の画面には「YouTube アカウントの管理」と表示されますが、本アプリが行うのは読むことだけで、動画・コメント・チャンネルを変更したり、投稿したりはしません（Google の許可の分け方の都合で、読むだけの許可では足りない機能があるため、この許可を頼んでいます）

2.3 チャットとその参加者

本アプリは、ご覧になっている配信のチャット（本文・表示名・アイコン・チャンネル ID など、YouTube の画面に出ている情報）を読み、この PC に記録します。

3. 使う目的

扱う情報は、次の目的にだけ使います。

  • YouTube ライブのチャットを表示すること
  • チャットにコメントを送ること（本アプリの中に開く YouTube のチャット画面から送ります）
  • メッセージに添えたリンク・画像・ファイルの情報を、同じ配信を見ている本アプリの利用者に届けること
  • 配信者が、自分のチャンネルでリンク・画像・ファイルを添えられないように止めること
  • 不具合を調べて直すこと

広告には使いません。情報を売ることもありません。

4. 情報の置き場所

4.1 この PC に置くもの

次のものは、この PC の中にだけ置きます（場所の一覧は はじめかた にあります）。

  • YouTube と Google のログインの情報（Google のサインインの情報は暗号化して保存します）
  • アプリの設定
  • チャットの記録と絵文字の画像
    • はじめは、ご自身で消すまで残ります。設定で残す期間（30日・90日・365日）を選ぶと、それより前に最後に開いた配信の記録は自動で消えます
    • 設定で、記録を暗号化して保存することもできます
    • 場所と消し方は はじめかた をご覧ください

4.2 開発者のサーバーに届くもの

本アプリは、Cloudflare の上にある開発者のサーバーを使います。チャットの内容をサーバーへ送ることはありません。 サーバーに届くもの・残る期間は次のとおりです。

何が何のために残る期間
メッセージに添えたリンク・画像・ファイルの情報（包んだもの）同じ配信の利用者に届けるため。中身はアプリの中で包んでから送り、包みを開く値はサーバーに送りません。包んだものは、ほかの利用者が読めるよう、公開の置き場に写します7日で自動で削除
添えた人のチャンネル ID・配信者のチャンネル ID・添えたものの種類（リンク・画像・ファイル）他人になりすまして添えられないよう確かめるため・配信者の止める設定を守るため7日で自動で削除
Google のサインインのトークンの指紋（トークンそのものではなく、元に戻せない形）上の確かめのたびに Google に問い合わせないためトークンの有効期限まで（1時間ほど）
配信者が止める設定（チャンネル ID と、止めている種類）配信者が自分のチャンネルで、リンク・画像・ファイルを止められるようにするため配信者が受け付けに戻すまで
ロール（開発者が試験のために付ける役割と、そのチャンネル ID）試験中の機能を一部の人だけに出すため決めた期限まで（期限が来たら自動で削除）
不具合の自動報告（エラーの種類・回数・アプリの版・端末ごとの無作為な ID）不具合を調べるため。名前・チャットの本文・チャンネルは含みません。設定でオフにできます90日で自動で削除
不具合の報告（アプリの虫のボタンか Ctrl+Shift+B で、ご自身が送ったときだけ。説明の文・画面の写し〔付けないこともできます〕・動作の記録）不具合を調べるため対応が済んだら削除。最長90日で自動で削除
利用の集計（日ごとの利用の数など、数だけ）運用のため集計した数だけを残します

包みについての注意: 添えたものを包むのは、サーバーや、配信を見ていない人に中身を読みにくくするためです。ただし、包みを開く値は配信のチャットから導かれるので、その配信のチャットを持っている人や、手間をかけて推し量る人には開けることがあります。人に見られて困るものは添えないでください。

このほか、使いすぎを防ぐため、接続元の IP アドレスと端末ごとの無作為な ID を、短い時間だけ数えるのに使います（保存はしません）。サーバーへ問い合わせるときは、アプリの版も一緒に送ります。新しい版をお知らせするため・古い版で使えない機能を決めるために使い、保存はしません。おしらせを読むとき・Google のサインインのとき・アプリが YouTube のページを読むための手順書を取りに行くときも、サーバーに問い合わせます。

5. ほかのサービスとのやりとり

本アプリは、個人の情報を第三者に売ったり、貸したりしません。ただし、次のサービスとはやりとりをします。

  • Google／YouTube: YouTube のページとチャットの表示・コメントの送信・ログイン・Google のサインイン・一部の YouTube API の呼び出し（チャンネルを確かめるため）
  • Cloudflare: 開発者のサーバーの置き場です。4.2 のデータを預けています
  • Gofile: ファイルを添えたときだけ、そのファイルの置き場として使います。ファイルは暗号化してから送ります
  • Gyazo: 画像を添えたときだけ、ご自身の Gyazo のアカウントへ画像を上げます。開発者のサーバーは通りません。上げた画像は、URL を知っている人なら誰でも見られます。上げる前に確かめの画面を出します
  • 法令に基づいて開示を求められた場合

6. Google と YouTube のサービスについて

本アプリは YouTube API サービスを使っています。本アプリを使うことで、YouTube 利用規約 に同意したものとみなされます。Google での情報の扱いは Google プライバシーポリシー をご覧ください。

本アプリによる Google API サービスのユーザーデータの扱いは、Google API サービスのユーザーデータに関するポリシー（制限付き使用の要件を含む）に従います。

7. 情報の消し方

  • アプリの中で YouTube からログアウトする・Google のサインインをやめる（この PC のログインの情報が消えます）
  • 設定で、チャットの記録を残す期間を選ぶ。配信を閉じるときに、その記録を消すこともできます
  • アプリと記録をまるごと消す（手順は はじめかた をご覧ください）
  • Google アカウントの権限設定 から、本アプリの許可を取り消す
  • Gyazo に上げた画像は、Gyazo のサービスでご自身で消してください
  • サーバーのデータは 4.2 の期間で自動で消えます。それより早く消してほしいときは、お問い合わせ先までご連絡ください

8. 守るための取り組み

  • Google のサインインの情報は暗号化して、この PC に保存します
  • 通信は HTTPS で暗号化しています
  • サーバーには、本アプリが使うものだけを、上の期間だけ置きます

9. 子どもの情報

本アプリは、13歳未満の方を対象としていません。13歳未満の方の情報を、知りながら集めることはありません。
